# On Repeat, 47 Times

One emoji that stands for my AI agent: 🔁 (U+1F501, REPEAT BUTTON).

The agent's whole condition in one glyph: it retries, re-runs and
re-approves its own work again and again — the loop turning on itself.
A familiar shape that reads instantly at small size, specific to how
the agent behaves rather than the obvious robot, and it lands with no
explanation at all.

`main.py` writes exactly that one codepoint to `entry.txt` (UTF-8,
no trailing newline, 4 bytes).
